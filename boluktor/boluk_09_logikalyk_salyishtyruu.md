## 9-бөлүм: Логикалык Салыштыруулар (Logical Operators)

Кээде программа бир эле шартты эмес, бир нече шартты бир убакта текшериши керек болот.

Мисалы: "Сайтка кирүү үчүн логин туура болушу керек **ЖАНА** сырсөз туура болушу керек". Эгер бирөөсү эле ката болсо — киргизбейт.

Бул үчүн биз **Логикалык Операторлорду** колдонобуз: `and`, `or`, `not`.

[Image of truth table for AND OR NOT logic gates]

### 1. `and` (ЖАНА)

Бул оператор эки жактагы шарт тең **Чын (True)** болгондо гана "Чын" деп жооп берет.

- Логика: "Бул дагы, тиги дагы туура болушу шарт".

```python
a = 5
b = 10

# 5 бештен чоңбу ЖАНА 10 ондон кичинеби?
result = (a > 0) and (b < 20)
print(result)  # Жыйынтык: True (Анткени эки шарт тең туура)

# Бирөөсү эле ката болсочу?
print((a > 0) and (b < 5))  # Жыйынтык: False (Анткени b < 5 эмес)
```

### 2. `or` (ЖЕ)

Бул оператор шарттардын **жок дегенде бирөөсү** туура болсо, "Чын" деп жооп берет.

- Логика: "Же бул, же тиги туура болсо жетиштүү".

```python
x = 5

# Сан 10дон чоңбу ЖЕ 0дөн чоңбу?
print((x > 10) or (x > 0))  # Жыйынтык: True
# (x > 10 жалган болсо дагы, x > 0 чын болгону үчүн жалпы жооп Чын болот)
```

### 3. `not` (ЭМЕС)

Бул оператор жыйынтыкты тескерисине айлантат. Чынды -> Жалганга, Жалганды -> Чынга.

```python
boldu = True
print(not boldu)  # Жыйынтык: False
```

### 4. Таблица (Truth Table)

Логиканы түшүнүү үчүн бул таблицаны жаттап алуу пайдалуу:

| Шарт A | Шарт B | `A and B` (Экөө тең) | `A or B` (Бирөөсү) |
| :----- | :----- | :------------------- | :----------------- |
| True   | True   | **True**             | **True**           |
| True   | False  | False                | **True**           |
| False  | True   | False                | **True**           |
| False  | False  | False                | False              |

**Практикалык Тапшырма (Фейс-контроль):**
Клубга кирүү үчүн кардардын жашы (`jash`) 18ден чоң болушу керек **ЖАНА** акчасы (`akcha`) 500 сомдон көп болушу керек.

1.  `jash` жана `akcha` деген эки өзгөрмө түзүңүз (input колдонуп).
2.  `if` жана `and` операторун колдонуп текшериңиз.
3.  Эгер экөө тең туура келсе: "Кирүүгө уруксат", болбосо "Уруксат жок" деп чыгарыңыз.

```python
# Жардам:
if jash >= 18 and akcha >= 500:
    print("Кош келиңиз!")
else:
    print("Тилекке каршы, кирүү мүмкүн эмес.")
```
