# 7-бөлүм: Арифметикалык Операциялар (Math)

Python — бул абдан күчтүү калькулятор. Ал жөнөкөй кошуу-алуудан баштап, татаал инженердик эсептөөлөргө чейин аткара алат.

Төмөндөгү таблицада негизги белгилер көрсөтүлгөн:

| Белги | Аты         | Мисал     | Жыйынтык | Түшүндүрмө                             |
| :---- | :---------- | :-------- | :------- | :------------------------------------- |
| `+`   | Кошуу       | `5 + 3`   | `8`      | Эки санды кошот.                       |
| `-`   | Кемитүү     | `5 - 3`   | `2`      | Биринчиден экинчисин кемитет.          |
| `*`   | Көбөйтүү    | `5 * 3`   | `15`     | Сандарды көбөйтөт.                     |
| `/`   | Бөлүү       | `10 / 2`  | `5.0`    | **Ар дайым** бөлчөк сан (float) берет. |
| `//`  | Бүтүн бөлүү | `10 // 3` | `3`      | Үтүрдөн кийинкисин алып салат.         |
| `%`   | Калдык      | `10 % 3`  | `1`      | Бөлгөндөн кийинки калдык.              |
| `**`  | Даража      | `2 ** 3`  | `8`      | 2нин 3-даражасы ($2^3$).               |

### 1. Бөлүү түрлөрү: `/`, `//` жана `%`

Жаңы үйрөнүп жаткандар үчүн эң маанилүү жери — бөлүүнүн түрлөрүн түшүнүү.

- **Кадимки бөлүү (`/`):**
  Математикадагыдай так жыйынтык берет.

  ```python
  print(7 / 2)   # Жыйынтык: 3.5
  ```

- **Бүтүн бөлүү (`//`):**
  Бул "полго чейин тегеректөө" деп аталат. Бөлчөк бөлүгүн кесип таштайт.

  ```python
  print(7 // 2)  # Жыйынтык: 3 (0.5 жоголду)
  ```

- **Калдык алуу (`%`):**
  Бул оператор бизге бөлгөндөн ашып калган "калдыкты" гана берет.
  ```python
  print(7 % 2)   # Жыйынтык: 1 (3төн 2 жолу бар, 1 калып калды)
  ```
  > **Колдонулушу:** `%` оператору сандын жуп же так экенин аныктоо үчүн көп колдонулат. Эгер `сан % 2 == 0` болсо, ал жуп сан.

### 2. Амалдардын тартиби (Order of Operations)

Мектептеги математика сыяктуу эле, Python амалдарды атайын тартип менен аткарат:

1.  Кашаалар `()` — биринчи аткарылат.
2.  Даража `**`.
3.  Көбөйтүү, Бөлүү, Калдык `*`, `/`, `//`, `%` (солдон оңго карай).
4.  Кошуу жана Кемитүү `+`, `-`.

```python
x = 2 + 3 * 4
print(x)  # Жыйынтык: 14 (анткени адегенде 3*4=12, анан +2)

y = (2 + 3) * 4
print(y)  # Жыйынтык: 20 (анткени адегенде кашаа ичи 2+3=5, анан *4)
```
