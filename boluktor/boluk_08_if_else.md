## 8-бөлүм: Шарттуу Операторлор (if/else) — Чечим Кабыл Алуу

Программа дайыма эле түз сызык менен (жогорудан төмөн) жүрө бербейт. Кээде ал кырдаалга жараша **чечим кабыл алышы** керек болот.

Мисалы: "Эгер жамгыр жааса — кол чатыр ал, болбосо — күндөн коргоочу көз айнек тагын".

Программалоодо муну **Шарттуу Операторлор** (Conditional Statements) аткарат.

### 1. `if` жана `else` түзүлүшү

Python тилинде биз англисче сөздөрдү колдонобуз:

- **`if`** — "Эгерде..." (Шартты текшерет)
- **`else`** — "Болбосо..." (Эгер шарт туура эмес болуп калса, эмне кылуу керек?)

```python
jash = int(input("Жашыңыз канчада? "))

if jash >= 18:
    # Эгер шарт Чын (True) болсо, бул блок иштейт:
    print("Сиз чоң кишисиз, кирүүгө уруксат.")
else:
    # Эгер шарт Жалган (False) болсо, бул блок иштейт:
    print("Сиз али жашсыз, күтө туруңуз.")
```

### 2. Чегинүү (Indentation) — Өтө маанилүү!

Башка тилдерде `{ }` кашаалар колдонулса, Python-до **боштук (пробел)** колдонулат.
`if` же `else` сөзүнөн кийинки сап сөзсүз түрдө **4 пробел (же 1 Tab)** оңго жылышы керек.

> **Эреже:** Эгер чегинүү (отступ) калтырбасаңыз, Python `IndentationError` деген ката берет.

### 3. `elif` — Үчүнчү жол

Кээде эки эле жол эмес, бир нече вариант болушу мүмкүн. Анда биз **`elif`** (else if — болбосо эгерде) колдонобуз.

```python
upay = 85

if upay >= 90:
    print("Бааңыз: 5 (Эң жакшы)")
elif upay >= 70:
    print("Бааңыз: 4 (Жакшы)")
elif upay >= 50:
    print("Бааңыз: 3 (Орточо)")
else:
    print("Бааңыз: 2 (Канааттандырарлык эмес)")
```

### 4. Салыштыруу Операторлору

Шарттарды жазуу үчүн төмөнкү белгилерди билишиңиз керек:

| Белги | Мааниси              | Мисал    |
| :---- | :------------------- | :------- |
| `==`  | Барабарбы?           | `a == b` |
| `!=`  | Барабар ЭМЕСпи?      | `a != b` |
| `>`   | Чоңбу?               | `a > b`  |
| `<`   | Кичинеби?            | `a < b`  |
| `>=`  | Чоң же барабарбы?    | `a >= b` |
| `<=`  | Кичине же барабарбы? | `a <= b` |

> **Көңүл буруңуз:** `=` (бир белги) — бул маани берүү (ыйгаруу). `==` (эки белги) — бул салыштыруу! "a = 5" десеңиз, ага 5ти саласыз. "a == 5" десеңиз, "а 5ке барабарбы?" деп сурайсыз.

---

**Практикалык Тапшырма (Жуп же Так):**
Келгиле, мурунку бөлүмдөгү `%` (калдык) операторун колдонолу.

1.  Колдонуучудан бир бүтүн сан сураңыз.
2.  Эгер ал санды 2ге бөлгөндө калдык (`%`) 0 болсо — "Бул жуп сан" деп чыгарсын.
3.  Болбосо — "Бул так сан" деп чыгарсын.

```python
# Жардам:
san = int(input("Сан жазыңыз: "))
if san % 2 == 0:
    print("Жуп сан")
else:
    print("Так сан")
```
