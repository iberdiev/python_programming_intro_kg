# 4-бөлүм: Өзгөрмөлөр (Variables) — Маалыматты Сактоо

Программалоону үйрөнүп жатканда, компьютерди чоң кампа (склад) катары элестетиңиз. Ал эми **өзгөрмө** (variable) — ошол кампадагы буюм сакталган **кутуча**.

Биз ар бир кутучага (өзгөрмөгө) уникалдуу ат коюп, анын ичине маалымат салабыз. Программа иштеп жатканда биз ошол атты чакырсак, компьютер бизге кутучанын ичиндеги нерсени алып берет.

### 1. Өзгөрмөнү түзүү (Assignment)

Python тилинде өзгөрмө түзүү үчүн `=` (барабар) белгисин колдонобуз. Бирок, бул математикадагы "барабар" дегенди түшүндүрбөйт! Программалоодо муну **ыйгаруу оператору** (assignment operator) деп атайбыз.

**Формуласы:** `Аты = Мааниси`

```python
# "message" деген кутуча ачып, ичине текст салабыз
message = "Салам, Python!"

# "jash" деген кутуча ачып, ичине сан салабыз
jash = 18

print(message)  # Экранга: Салам, Python!
print(jash)     # Экранга: 18
```
