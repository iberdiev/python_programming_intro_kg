# 5-бөлүм: Маалымат Түрлөрү (Data Types)

Биз жашоодо "бул — сөз", "бул — сан", "бул — чындык" деп маалыматты өзүбүзчө бөлөбүз. Компьютер дагы маалыматты иштетүү үчүн анын **түрүн** (type) так билиши керек.

Сиз текстти көбөйтө албайсыз (мисалы, `"салам" * "алма"` мүмкүн эмес), бирок сандарды көбөйтө аласыз. Ошондуктан Python ар бир өзгөрмөнү катуу көзөмөлдөйт.



### 1. Сап (String) — `str`
Бул жөнөкөй текст. Аты айтып тургандай, бул символдордун тизмеги (жиби).
* **Белгиси:** Текст ар дайым **тырмакчага** алынат: `" "` же `' '`.
* **Мисал:** Аттар, сүйлөмдөр, телефон номерлер.

```python
aty = "Айбек"
shaar = 'Бишкек'
nomer = "+996555123"  # Бул дагы текст (str), анткени тырмакчада!
