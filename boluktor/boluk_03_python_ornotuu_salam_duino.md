# Бөлүк 3: Python орнотуу жана «Салам, дүйнө!»

Python'ду орнотуу:
- [python.org] сайтынан жүктөп орнотуңуз.

Алгачкы программа:
```python
# Экранга текст чыгаруу
print("Салам, дүйнө!")
```

**Эмне болду?** `print(...)` — экранга маалымат чыгарат.

**`print()` функциясы тууралуу кененирээк:**

`print()` функциясы — Pythonдогу эң негизги функциялардын бири. Анын жардамы менен сиз программаңыздан текстти, сандарды же башка маалыматтарды колдонуучуга көрсөтө аласыз.

Мисалы:
- `print("Бул текст.")` — экранга "Бул текст." деген жазууну чыгарат.
- `print(123)` — экранга 123 санын чыгарат.
- Сиз бир нече нерсени үтүр (`,`) менен бөлүп чыгара аласыз: `print("Менин атым", "Айбек", "жана мен", 25, "жаштамын.")` Бул учурда, ар бир бөлүкчөнүн ортосуна автоматтык түрдө боштук кошулуп чыгарылат.
- Ар бир `print()` чакыруусу демейки боюнча жаңы сапка өтөт.

**Тапшырма:** Өз атыңыз менен саламдашуучу текст чыгарыңыз.
