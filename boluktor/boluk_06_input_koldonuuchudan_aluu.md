## 6-бөлүм: Колдонуучудан Маалымат Алуу (User Input)

Ушул кезге чейин биз өзгөрмөлөрдүн маанисин коддун ичине өзүбүз жазып жаттык. Бирок чыныгы программалар колдонуучу менен сүйлөшө билиши керек (мисалы: логин суроо, баа суроо).

Python тилинде колдонуучудан маалымат алуу үчүн `input()` функциясы колдонулат.

### 1. Жөнөкөй текст алуу

`input()` иштегенде, программа **токтоп**, колдонуучу бир нерсе жазып, **Enter** баскычын басканча күтүп турат.

```python
print("Саламатсызбы!")
aty = input("Сиздин атыңыз ким? ")  # Программа күтөт...

print("Таанышканыма кубанычтамын, " + aty + "!")
```

### 2. "Сап" көйгөйү (The String Trap)

`input()` аркылуу келген **бардык** маалыматты Python **текст (String)** катары кабыл алат. Эгер сиз `10` деп жазсаңыз да, ал компьютер үчүн `"10"` (текст) болуп саналат.

Эгер биз аны санга айландырбасак, математика ката иштейт:

```python
a = input("Биринчи сан: ")  # Мисалы: 10
b = input("Экинчи сан: ")   # Мисалы: 20

print(a + b)  # Жыйынтык: 1020 (30 эмес!)
# Анткени ал эки сөздү бириктирип койду ("10" + "20").
```

### 3. Санга айландыруу (Type Casting)

Математикалык амалдарды аткаруу үчүн, биз келген текстти атайын "котормочу" функциялар менен санга айландырышыбыз керек:

- `int()` — бүтүн санга айландырат.
- `float()` — бөлчөк санга айландырат.

**Туура жол:**

```python
# Бүтүн сан алуу
jash = int(input("Жашыңыз канчада? "))
print("Келерки жылы сиз", jash + 1, "жашка чыгасыз.")

# Бөлчөк сан алуу (мисалы, баа, салмак)
salmak = float(input("Салмагыңыз канча (кг)? "))
print("Сиздин салмагыңыз:", salmak)
```

> **Эскертүү:** Эгер колдонуучу сандын ордуна сөз жазып койсо (мисалы, "он беш"), `int()` функциясы ката (ValueError) берет. Программа "цифра күткөм, бирок сөз келди" деп токтоп калат.
