# 6-бөлүм: Колдонуучудан Маалымат Алуу (User Input)

Ушул кезге чейин биз өзгөрмөлөрдүн маанисин коддун ичине өзүбүз жазып жаттык. Бирок чыныгы программалар колдонуучу менен сүйлөшө билиши керек (мисалы: логин суроо, баа суроо).

Python тилинде колдонуучудан маалымат алуу үчүн `input()` функциясы колдонулат.

### 1. Жөнөкөй текст алуу
`input()` иштегенде, программа **токтоп**, колдонуучу бир нерсе жазып, **Enter** баскычын басканча күтүп турат.

```python
print("Саламатсызбы!")
aty = input("Сиздин атыңыз ким? ")  # Программа күтөт...

print("Таанышканыма кубанычтамын, " + aty + "!")
