# Python менен программалоого киришүү

Бул эксперименталдык репозиторий жаңы баштагандар үчүн Python аркылуу программалоонун негиздерин кыргыз тилинде үйрөтүү үчүн түзүлгөн.
Эгер сиз бул долбоорго салым кошсоңуз, мен ыраазы болот элем.

## Кантип колдонуу керек

- **boluktor/** папкасында ар бир бөлүм өзүнчө Markdown файл болуп жайгашкан.
- Python 3.10+ версиясы жарайт. Онлайн үчүн: Google Colab ж.б.у.с. сайттарды колдоно аласыз.
